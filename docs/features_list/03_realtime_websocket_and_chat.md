# Feature List 03: Real-Time Communication and Chat State Sync

This document expands upon Study Guide 03 by providing an exhaustive list of features supported by the real-time websocket architecture and messaging systems.

## 1. WebSocket Infrastructure & Connection Management
*   **Centralized Connection Registry (`ConnectionManager`):** Tracking active WebSocket sessions linked to user IDs.
*   **Authentication Handshake:** JWT token validation during the initial WebSocket upgrade request.
*   **Cross-Service Sync (Redis):** Utilizing Redis pub/sub to synchronize presence states across multiple FastAPI worker nodes.
*   **Presence Lifecycle Monitoring:** Broadcasting `ONLINE` and `OFFLINE` status changes to relevant peers.
*   **Graceful Disconnect Handling:** Proper cleanup of disconnected sockets and Redis state upon client exit.

## 2. Chat Network Synchronization
*   **Message Dispatch Pipeline:**
    *   Routing incoming WebSocket frames to designated chat rooms.
    *   Determining recipient online status.
*   **Message Deduplication:** Processing unique `client_message_id` UUIDs generated by Android to prevent ghost duplicates on retry.
*   **Delivery and Read Receipts:** Tracking and broadcasting state changes (`SENT`, `DELIVERED`, `READ`).
*   **Offline Queueing / Persistence:** Saving messages to the PostgreSQL database for delivery upon subsequent login.
*   **Firebase Cloud Messaging (FCM) Integration:**
    *   Dispatching push notifications to offline recipients.
    *   FCM device token registry (`FcmToken` model) management.
*   **Chat History Retrieval:** Paginated REST API endpoints for fetching historical messages.
